## 📝 Инструкции для запуска

### 1. Установка зависимостей

```bash
cd apps/web
npm install
```

### 2. Запуск dev-сервера

```bash
npm run dev
```

Откройте http://localhost:3000

### 3. Переключение языков

- http://localhost:3000/ky — кыргызский
- http://localhost:3000/ru — русский (default)
- http://localhost:3000/en — английский

### 4. Production build

```bash
npm run build
npm start
```
