## 🚀 Deploy в 3 Шага

### 1. Подготовка (30 мин)
- Создать Neon Database
- Создать Upstash Redis
- Настроить Google OAuth
- Сгенерировать секреты

### 2. Deploy (30 мин)
- Push в GitHub
- Deploy API на Vercel
- Deploy Web на Vercel
- Настроить environment variables

### 3. Проверка (15 мин)
- Протестировать все apps
- Обновить OAuth URLs
- Проверить health checks

**Полный гайд**: [VERCEL-DEPLOYMENT-GUIDE.md](./VERCEL-DEPLOYMENT-GUIDE.md)
