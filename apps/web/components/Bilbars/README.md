# Система Анимаций Билбарса

Интерактивная система анимаций талисмана ОКУРМЭН - Билбарса, созданная с использованием Framer Motion и React.

## 📁 Структура Компонентов

### 1. **BilbarsCharacter.tsx**
Базовый компонент персонажа с системой состояний.

**Состояния:**
- `idle` - спокойное состояние с лёгким покачиванием
- `happy` - радостное состояние с подпрыгиванием
- `wave` - приветствие с поднятием лапы
- `jump` - высокий прыжок
- `laugh` - смех с вращением
- `surprised` - удивление
- `thinking` - задумчивость с наклоном головы
- `reading` - Билбарс с книгой
- `backpack` - Билбарс с рюкзаком
- `celebrate` - праздничное состояние
- `laptop` - Билбарс с ноутбуком
- `sitting` - сидячая поза

**Props:**
```tsx
{
  state?: BilbarsState;
  size?: 'sm' | 'md' | 'lg' | 'xl';
  className?: string;
  onClick?: () => void;
  onMouseEnter?: () => void;
  onMouseLeave?: () => void;
  autoAnimate?: boolean;
  floatingEffect?: boolean;
}
```

### 2. **BilbarsIntro.tsx**
Intro-анимация при первом открытии сайта.

**Последовательность:**
1. Билбарс появляется с эффектом bounce (0.8s)
2. Машет лапой в приветствии (2.5s)
3. Перемещается в сторону (3.5s)
4. Появляется логотип ОКУРМЭН (5.5s)
5. Переход к основному контенту

**Особенности:**
- Использует `sessionStorage` для показа один раз за сессию
- Автоматически завершается через ~5.5 секунд
- Плавные переходы между стадиями

### 3. **BilbarsHeroCard.tsx**
Билбарс в Hero-секции, автоматически меняющий состояния.

**Цикл:**
- 0-6 сек: Билбарс читает книгу
- 6-12 сек: Билбарс с рюкзаком
- Цикл повторяется бесконечно

**Особенности:**
- Плавная смена состояний с crossfade
- Floating эффект
- Декоративные частицы вокруг
- Индикатор текущего состояния внизу
- Интерактивность при клике

### 4. **BilbarsFloatingMascot.tsx**
Билбарс над блоком курсов с вариативной анимацией.

**Анимационный цикл:**
- idle → happy → thinking → laugh → wave
- Разные интервалы (2-4 сек) для естественности
- Речевой пузырь "Выбери курс! 🎓"
- Искры вокруг персонажа

### 5. **BilbarsScrollReactive.tsx**
Билбарс, реагирующий на прокрутку страницы.

**Реакции:**
- Движется вправо/влево в зависимости от scroll progress
- Меняет состояния: idle → thinking → happy → wave → celebrate
- Плавное изменение размера и прозрачности
- Исчезает на 95% прокрутки
- Использует spring-физику для плавности

### 6. **BilbarsIntroWrapper.tsx**
Обёртка для управления intro и scroll-реактивным Билбарсом.

## ⚡ Производительность

### Оптимизации:
- Использование `transform` и `opacity` для GPU-ускорения
- Lazy loading изображений через Next.js Image
- Debouncing scroll events
- Spring-физика с оптимальными параметрами
- Отключение анимаций при `prefers-reduced-motion`

### CSS Support:
```css
@media (prefers-reduced-motion: reduce) {
  /* Все анимации отключаются */
  animation: none !important;
}
```

## 📱 Адаптивность

- **Desktop (1024px+)**: Полный набор анимаций
- **Tablet (768-1023px)**: Уменьшенный размер, упрощённые анимации
- **Mobile (< 768px)**: Компактный размер, минимальные анимации, scroll-reactive скрыт

## 🎭 Состояния Анимации

Каждое состояние имеет уникальную анимацию через Framer Motion:

```tsx
const stateAnimations = {
  idle: { y: [0, -8, 0], duration: 3s },
  happy: { scale: [1, 1.05, 1], y: [0, -12, 0] },
  wave: { rotate: [0, -10, 10, -10, 0] },
  jump: { y: [0, -40, 0], duration: 0.8s },
  // ... и т.д.
}
```

## 🐛 Troubleshooting

### Билбарс не появляется:
1. Проверьте, что изображения в `/public/bilbars/`
2. Очистите sessionStorage: `sessionStorage.clear()`
3. Проверьте console на ошибки загрузки

### Анимации слишком быстрые/медленные:
- Отрегулируйте `duration` в компонентах
- Измените интервалы в `useEffect`

### Производительность:
- Проверьте `prefers-reduced-motion`
- Уменьшите количество floating particles
- Используйте `will-change: transform` осторожно
