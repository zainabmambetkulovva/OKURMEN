## 🔄 Процесс деплоя

### Этап 1: Локальная подготовка
```
┌─────────────────┐
│ Локальный код   │
│ git commit      │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ vercel --prod   │
│ (команда)       │
└────────┬────────┘
```

### Этап 2: Vercel Build
```
         │
         ▼
┌─────────────────┐
│ Vercel Platform │
│ - Clone repo    │
│ - npm install   │
│ - npm run build │
└────────┬────────┘
```

### Этап 3: Deployment
```
         │
         ▼
┌─────────────────┐
│ CDN Deployment  │
│ - Static files  │
│ - Serverless    │
│ - Edge network  │
└────────┬────────┘
```

### Этап 4: Live
```
         │
         ▼
┌─────────────────┐
│  🎉 LIVE URL    │
│ okurmen.app     │
└─────────────────┘
```
